# Day 1 – Introduction to Verilog RTL Design and Synthesis

## Objective

The objective of Day 1 was to understand the basic RTL design flow using Verilog HDL, perform functional simulation, synthesize the RTL using Yosys, and generate a gate-level netlist using the SKY130 Standard Cell Library.

---

## Experiment

### Design Implemented

**2:1 Multiplexer (good_mux)**

The multiplexer selects one of two input signals based on the select signal.

### Truth Table

| sel | y |
|:---:|:-:|
| 0 | i0 |
| 1 | i1 |

## RTL Design

The RTL was implemented using a behavioral Verilog description with a simple `if-else` statement.

---

## Functional Simulation

### Compile

```bash
iverilog good_mux.v tb_good_mux.v
```

### Run Simulation

```bash
./a.out
```

### Open Waveform

```bash
gtkwave tb_good_mux.vcd
```

---

## RTL Synthesis

Start Yosys

```bash
yosys
```

Execute the following commands:

```tcl
read_liberty -lib ../lib/sky130_fd_sc_hd__tt_025C_1v80.lib

read_verilog good_mux.v

synth -top good_mux

abc -liberty ../lib/sky130_fd_sc_hd__tt_025C_1v80.lib

write_verilog good_mux_netlist.v
```
